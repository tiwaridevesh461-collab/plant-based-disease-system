 PhytoScan 🌿

PhytoScan is a lightweight, frontend-only web application that uses AI to detect plant diseases and analyze crop health. By connecting directly to OpenRouter's vision models (like GPT-4o or Claude 3.5 Sonnet), it provides instant, structured agronomic reports.

✨ Features

Bring Your Own Key (BYOK): Connects directly to OpenRouter from the browser—no backend required.

Instant Analysis: Upload plant/leaf images for real-time pathology reports.

Interactive UI: Features a sleek dark-mode design with an interactive 3D plant model.

🚀 Quick Start

Clone & Open: Clone this repository and double-click index.html to open it in any web browser.

Configure API: Get an API key from OpenRouter and paste it into the API Configuration section on the page.

Analyze: Upload an image of a plant and click "Execute Analysis".

Note: Your API key is stored only in your browser's local memory and is sent directly to OpenRouter.

🛠️ Tech Stack

HTML5, Vanilla JavaScript

Tailwind CSS (via CDN)

@google/model-viewer for 3D rendering

OpenRouter API for LMM processing

🌍 Deployment

Drop the project folder into GitHub Pages, Netlify, or Vercel to host it for free instantly.
